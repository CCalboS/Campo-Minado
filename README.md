# 💣 Campo Minado

Uma implementação do clássico **Campo Minado** desenvolvida em **C# utilizando o Visual Studio 2022**.

Este projeto foi criado como uma forma de praticar **lógica de programação, estruturas condicionais, manipulação de coordenadas e interação com o usuário**, transformando um jogo clássico em uma experiência prática de desenvolvimento.

A lógica do tabuleiro foi construída utilizando as **posições X e Y dos quadrados**, em vez de uma matriz tradicional. Essa abordagem fez parte dos desafios de lógica encontrados durante o desenvolvimento e foi uma oportunidade de experimentar diferentes formas de representar e controlar os elementos do jogo.

Assim como outros projetos desenvolvidos durante meu aprendizado, o foco aqui não foi criar a implementação mais otimizada ou seguir as melhores práticas de arquitetura, mas sim **entender os problemas, encontrar soluções e fazer o jogo funcionar**.

O código representa uma etapa do meu aprendizado em C# e, por isso, pode conter implementações que hoje eu desenvolveria de maneiras diferentes ou mais eficientes.

## 🎯 Objetivos do projeto

* Praticar C# e lógica de programação;
* Trabalhar com coordenadas X e Y;
* Implementar a lógica do Campo Minado;
* Manipular o posicionamento e os estados dos elementos;
* Desenvolver um projeto completo partindo do zero;
* Aprender através da prática e da resolução de problemas.

## 🎮 Sobre o jogo

O objetivo é o mesmo do clássico Campo Minado: **revelar todas as áreas seguras do tabuleiro sem encontrar uma mina**.

Cada partida exige atenção e raciocínio para interpretar as informações disponíveis e descobrir onde as minas estão escondidas.

> **Projetos simples também ensinam coisas complexas. Às vezes, alguns quadrados e suas coordenadas são suficientes para transformar lógica em diversão.**
